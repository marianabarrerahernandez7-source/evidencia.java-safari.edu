# 🦒 Safari.Edu

**Aplicación educativa para niños** con animalitos divertidos.

## Descripción
Proyecto desarrollado para la evidencia **GA7-220501096-AA2-EV01** del SENA.  
Permite registrar usuarios y guardar información en base de datos MySQL usando JDBC.

## Tecnologías utilizadas
- Java
- MySQL + JDBC
- Estructura en paquetes (MVC básico)

## Cómo ejecutar
1. Asegúrate de tener la base de datos `safari_edu` creada.
2. Coloca el driver MySQL en la carpeta `lib`.
3. Ejecuta la clase `Main.java`.
